# NHC Healthcare Data Analysis Project

This repository presents a series of Jupyter notebooks demonstrating core skills in healthcare data analysis using Python. These projects were developed as practical exercises in data wrangling, exploratory analysis, visualization, and forecasting to derive insights from healthcare datasets. This Project primarily serves as practice for learning and demonstrating fundamental knowledge of pandas. 

## Project Overview

### 1. Data Cleaning & Preparation
- Cleaned and reformatted raw medication data using pandas
- Fixed formatting issues and organized data into a structured dataset
- Used string operations and regex to separate medication names and classes
- Exported cleaned data for analysis

### 2. Pharmacy Sales Analysis
- Explored and analyzed medication sales data with pandas
- Identified top-selling medication categories using grouping and aggregation
- Created visualizations with matplotlib and seaborn
- Used Prophet for basic sales forecasting

### 3. Patient Visit Analysis
- Cleaned and prepared hospital visit data
- Analyzed patient demographics and visit trends
- Visualized patient volume and cost-related patterns
- Evaluated basic hospital performance metrics

## Skills Used
